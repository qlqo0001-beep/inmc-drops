# inmc-drops

바닐라 몹 사냥·블록 채굴·농사의 **기본 드랍은 그대로 두고**, 관리자가 등록한 아이템을 % 로 **더해서** 떨군다.
인첸트에서 2026-09-25 에 뺀 "몹이 미확인 부여서를 떨구던 기능"도 여기서 다시 한다(공통 표 "적대 몹"에 부여서를 넣는다).

사용법은 `GUIDE.md`, 바꾼 것은 `CHANGELOG.md`.

## 표

| 종류 | 무엇 | 목록은 어디서 | 확률 |
|---|---|---|---|
| 몹 | 몹 하나 | **게임에서** — `EntityType` 의 살아 있는 것 전부(플레이어·갑옷 거치대·마네킹 빼고). 새 버전의 몹도 켤 때 자동 | 사람 확률 × 약탈 보너스 |
| 작물 | 작물 하나 | 기본 16종 + **켤 때 `#minecraft:crops` 태그에서 새로 보이는 것** + 관리자가 추가한 것 | 사람 확률 × 행운 보너스, **자동 농사 확률은 항목마다 따로** |
| 블록 | 블록 여럿(광석 + 심층암 쌍둥이) | **관리자가 등록한 것만** | 사람 확률 × 행운 보너스 |
| 공통 | 모든 몹·적대 몹(`Enemy`)·동물(`Animals`)·모든 작물 | 고정 넷 | 그 몹·작물의 표와 **따로** 굴린다 |

**편집한 표만 파일이 생긴다**(`tables/<종류>/<id>.yml`). 몹·작물은 목록이 게임에서 오므로 빈 파일 80개 없이 "자동 등록"이 된다.
항목은 urb 의 상자 보상(`inmc-urb/…/box/Reward.kt`)과 같은 칸에 **자동 농사 확률**·**정보에서 숨기기**를 더했다. 항목마다 따로 굴린다.

### 작물 판정 규칙

| 규칙 | 작물 | 나오는 때 |
|---|---|---|
| 다 자람 | 밀·당근·감자·비트·네더 사마귀·코코아·`pitcher_crop`, 태그에서 새로 보이는 것 | 나이가 최대 |
| 열매 | 달콤한 열매 덤불(나이 2 이상)·발광 열매(`berries`) | 열매가 달렸을 때 — 우클릭 수확도 |
| 자연 생성 | 수박·호박·사탕수수·선인장·대나무·켈프·횃불꽃 | **놓은 블록이 아닐 때**(줄기에 맺히거나 자라난 것) |

줄기(`_STEM`)는 작물이 아니다(캐는 것은 수확이 아니다). 횃불꽃 작물은 다 자라면 횃불꽃으로 바뀌어 그것을 캔다. **후렴초는 넣지 않는다** —
커스텀아이템이 커스텀 블록에 빌려 쓴다.

## 판정 (`listener/DropListener.kt`)

전부 **MONITOR + `ignoreCancelled`**. 보호 플러그인(Lands·WorldGuard …)이 막은 파괴·처치는 여기 오지 않는다 — 그래서 보호 플러그인과
따로 연동하지 않는다.

| 사건 | 조건 |
|---|---|
| `EntityDeathEvent` | `killer`(플레이어) 있음 — 바닐라의 "플레이어 처치" 판정 그대로 · 처치자 서바이벌/모험 · 커스텀 몹 아님 · 월드 켜짐 |
| `BlockBreakEvent` | 서바이벌/모험 · `isDropItems` · **놓은 블록 아님** · **섬세한 손길 아님** · (블록) 맞는 도구가 필요한 블록이면 맞는 도구 · (작물) 규칙 통과 · 월드 켜짐 |
| `PlayerHarvestBlockEvent` | 열매 규칙의 작물 우클릭 |
| `BlockBreakBlockEvent`(피스톤·물) · `BlockDestroyEvent`(받침 무너짐·주민 …, `willDrop`) | 작물만 · 규칙 통과 · 놓은 블록 아님 · **청크당 1시간 상한** → 자동 농사 확률, 주인 없음 |

- **같은 틱·같은 자리는 한 번만** 센다 — 사람이 캔 블록에 다른 파괴 사건이 따라와도 두 번 주지 않는다.
- 폭발·화염으로 부서진 것은 안 나온다. 인첸트 광역 채굴(트렌치·광맥)은 블록마다 진짜 `BlockBreakEvent` 를 쏘므로 **나온다**.
- 최종 확률 = 기본 × (1 + 보너스% × 레벨) × 이벤트 배율, 0~100.

## 복사를 막는 것

- **섬세한 손길이면 언제나 없다**(사용자 결정) — 들고 가서 다시 놓는 반복의 시작을 끊는다.
- **놓은 블록 기록**(`track/PlacedBlocks.kt`) — 청크 PDC `inmcdrops:placed`(정수 배열, 커스텀아이템 후렴초 표시와 같은 방식). 놓은 자리를
  캐면 안 나온다. 사탕수수·선인장은 놓은 칸만 안 나오고 자라난 칸은 나온다.
  - 적는 블록 = 블록 표의 대상 + 자연 생성 작물. 모든 블록을 적으면 큰 건물 청크가 무거워진다. 대가: **표를 나중에 만든 블록**은 그 전에
    놓인 것이 기록이 없어 한 번은 나온다(캐면 끝이라 반복은 안 된다).
  - 따라감(`listener/TrackListener.kt`): 피스톤(밀리는 것만 — 목록에 부서지는 것도 섞여 온다), 떨어지는 블록(엔티티 PDC 로), 엔더맨.
    지움: 캐기·폭발·불·잎 시듦·몹이 바꿈·**자라서 생긴 블록**(그 자리의 낡은 기록).
- **자동 농사 상한** — 자동 농장은 사람이 없어도 돌아서, 상한이 없으면 끝없이 나온다. 자동 농사 확률은 처음에 0.

## 다른 플러그인과의 경계

- **인첸트**: 배수·제련·가방으로가 커스텀 드랍에 걸리지 않게 이벤트 목록에 넣지 않고 **따로 떨군다**(인첸트는 HIGH 에서 목록을 고친다).
- **커스텀아이템**: 커스텀 블록은 `isDropItems` 를 꺼 둬 자동으로 빠진다. 배낭 자동 수납(HIGH, `ignoreCancelled`)은 줍기 보호(LOW 취소)를 존중한다.
  등록한 커스텀아이템은 참조로 저장돼 떨굴 때마다 원본 정의로 새로 만든다 — 미확인 부여서는 인첸트의 `factory` 가 매번 새로.
- **몬스터**: 엔티티 PDC `inmc-monster:mob_id` 가 **비어 있지 않으면** 커스텀 몹이라 건너뛴다(자기 드랍 표가 있다). 수식어만 붙은 바닐라 몹은
  빈 값이라 우리 표가 적용된다. 클래스에 기대지 않으려고 PDC 로 본다.
- **업적**: 신호 `drops/drop`(사람이 만든 드랍만 — subject = 아이템 참조, data = category·table·auto, amount = 개수).
- **줍기 보호**: 몬스터 `death/DropService.kt` 와 같은 방식(주인·만료를 아이템 엔티티 PDC 에, LOW 에서 비교).

## 파일

| 파일 | 내용 |
|---|---|
| `config.yml` | 기본 확률 · 줍기 보호 초 · 자동 농사 상한 · 월드별(목록 — 월드 이름의 점 때문에) |
| `messages.yml` | 메시지 |
| `tables/mob·crop·block·group/<id>.yml` | 표. 손으로 고치려면 서버를 끄고 |
| `stats.yml` | 항목별로 나온 횟수 |
| `state.yml` | 진행 중인 드랍 이벤트(배율·시작·끝 시각) |
| `verify/drops-<시각>.txt` | `/드랍 검증` 결과 |
